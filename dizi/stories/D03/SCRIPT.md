# Çapkın Nihat · Bölüm 3 · "Vanilya"

Setler: salon penceresi (x≈200, sabah), antre (x≈100, sabah), **apartman merdiveni (x≈300, akşam — ev.js'e yeni eklendi:
sahanlık + alt kata inen sekiz basamak, Daire 7 (Ayça'lar) ve alt katta Daire 3; Daire 3'ün altından sıcak ışık sızar)**.
Ses: Ayça Vindemiatrix, Nihat Algenib. Vanilya = ileride Selin'in (alt kat) kokusu; burada yalnız ima, yüzü gösterilmez.

| Sahne | Satır | Görüntü |
|---|---|---|
| Kanca 1 | Pazar sabahı. | Çamaşır sepetindeki bordo gömlek, Ayça'nın eli çeker |
| Kanca 2 | Dünkü gömleği çamaşır sepetindeydi. | Ayça pencerenin önünde, gömlek elinde |
| | Maçtan dönen bir adamın gömleği. Ter kokusu yok. | Gömleğe bakar |
| Koku | Vanilya kokuyordu. | Gömleği burnuna götürür, altın renkli kıvrımlar yükselir |
| | Ben vanilya sürmem. Hiç sürmedim. | Şaşkın, sonra endişeli |
| Ekran | Dünkü aramayı silmiştim. Nihat hiçbir şey anlamadı. | Son aramalar: "Bizim Takımdaki Kaan" kaydırılıp silinir |
| Yakın | Yakasında bir saç teli vardı. Uzun ve sarı. | Yaka yakın: uzun sarı saç teli (sert kesme) |
| | Benim saçım kestane. | Ayça'nın yüzü, kestane saçları |
| Yüzleşme | (Ayça) Bu saç kimin, Nihat? | Antre, Ayça gömleği uzatır |
| | (Nihat) Asansörde biri sürtündü herhalde. Kalabalıktı. | Nihat aynada yakasını düzeltir, sırıtır |
| | (Ayça) Halı sahanın asansörü mü var? | Ayça, kızgın |
| | (Nihat) Hayatım, bizim apartmanın asansörü. Hadi ama. | Nihat kollarını açar |
| | Gülümsedi. Yalan söylerken hep gülümser. | Nihat'a yavaş yaklaş |
| Merdiven | Akşam çöpü çıkarırken merdivende durdum. | Sahanlık, Ayça elinde çöp poşetiyle (sert kesme) |
| | Aynı koku. Vanilya. Alt kattan geliyordu. | Merdivenden alt kata: Daire 3'ün kapısı, altından ışık, vanilya izi yukarı süzülür |
| Son | Bu apartmanda vanilya kokan kim? | Ayça'ya yaklaş; son kart: 4. bölüm |
