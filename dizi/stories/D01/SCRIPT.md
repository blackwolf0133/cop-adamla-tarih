# Çapkın Nihat · Bölüm 1 · "Gece 02.14"

Dizi: Ayça (34) kocası Nihat'ın (38) onu aldattığından şüpheleniyor; her bölüm bir ipucu ve bir "acaba mı?" ile biter.
Anlatım: Ayça'nın iç sesi (alçak, sakin). Nihat ve Ayça'nın yüksek sesle söylediği satırlar ayrı.

| Sahne | Satır | Görüntü |
|---|---|---|
| Kanca 1 | Gece iki on dört. | Komodindeki dijital saat 02:14, yakın |
| Kanca 2 | Nihat'ın telefonu titredi. | Yüzüstü telefon titriyor, kenarlarından ışık sızıyor |
| Kanca 3 | Ben uyuyormuş gibi yaptım. | Ayça yastıkta, gözleri yarı açık, telefon ışığı yüzünde |
| Geniş | On iki yıllık evliyiz... yüzüstü koymazdı. | Yatak odası geniş: ikisi yatakta, duvarda düğün fotoğrafı |
| | Son üç aydır koyuyor. | Telefona yaklaş |
| Ekran | Ekran bir an yandı... Yarın aynı yerde mi? | Telefon ekranı yakın: mesaj balonu |
| | Gönderen: Bizim takımdaki Kaan. | Gönderen adı |
| Şok | Nihat futbol oynamaz ki. | Ayça'nın gözleri açılır |
| | (Nihat) Uyumadın mı sen? | Nihat lambayı yakar (sıcak ışık), yarı uykulu |
| | (Ayça) Su içmeye kalktım. | Ayça doğrulur |
| | Yalan söyledim... | Ayça karanlıkta yalnız, lamba söner |
| Sabah | Sabah her zamankinden erken... iki kez değiştirdi. | Antre: Nihat aynanın önünde, gömlek rengi değişir |
| | (Nihat) Akşam geç kalırım, mesai var. | Kapıda, Ayça çay bardağıyla bakar |
| Son | Aynı yer neresiydi, Nihat? | Ayça pencerede, yavaş yaklaş; son kart: 2. bölüm |
